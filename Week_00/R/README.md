# 🚀 How to Use the R Markdown Workbook

## Step 1 — Download the `.Rmd` file

Click:

**`DTS301_Week00_R_for_Data_Science_Student_Centered.Rmd`**

Then download the file to your computer.

---

## Step 2 — Open RStudio

Launch **RStudio** on your computer.

Then select:

**File → Open File**

and choose the downloaded `.Rmd` file.

---

## Step 3 — Work through the notebook

The workbook is designed to be completed **section by section**.

For each section:

1. Read the explanation.
2. Look at the worked example.
3. Predict what you think the code will do.
4. Run the code.
5. Inspect the output.
6. Explain what happened.
7. Complete the activity.

### Learning Cycle

> **Read → Predict → Run → Inspect → Explain → Reflect**

Do not simply run the code.

The goal is to understand **why the code works and what the output means**.

---

# ▶️ Running R Code in RStudio

R Markdown documents contain **code chunks**.

You can run an individual code chunk using the **Run** button associated with the chunk.

You can also run code line-by-line or run an entire section.

As you work, inspect:

- the Console
- the Environment
- plots
- tables
- warnings and errors

If an error occurs, read the error message before asking for help.

Your lecturer may specify which format should be submitted.

# 🔄 R Script Alternative

If you prefer working with a conventional R script:
