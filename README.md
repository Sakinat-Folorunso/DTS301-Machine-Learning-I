## About the Course

This repository contains the practical learning materials for **DTS 301 — Machine Learning I**.

The course is designed around a student-centred progression from:

> **Working with data → Understanding data → Representing data → Learning from data → Building and evaluating models**

The teaching philosophy is:

> **Problem first. Data second. Algorithm later.**

Each practical week follows:

**Read → Predict → Run → Inspect → Explain → Practise → Do It Yourself → Reflect → Bridge**

---

## Learning Pathways

Students may work through the practical materials using either:

- **Python** — Jupyter Notebook / Google Colab
- **R** — RStudio / R Markdown

The Python and R pathways are designed to teach the **same underlying data-science and machine-learning concepts**, while using the conventions of each language.

## Course Design Principles

### 1. Problem first

Students begin by understanding the problem before selecting an algorithm.

### 2. Data before modelling

Students inspect, clean, visualise and interpret data before modelling.

### 3. Concepts before syntax

Programming is used to reinforce data-science concepts rather than becoming the objective itself.

### 4. Active learning

Students repeatedly predict, run, inspect, explain and reflect.

### 5. Independent practice

Each week includes guided practical work followed by a **Do It Yourself** task.

### 6. Reflection

Students are encouraged to explain what they learned, what remains unclear and how the concepts connect to machine learning.
