# Week 1 — R

## Introduction to Machine Learning

This folder contains the **RStudio/R Markdown pathway** for Week 1 of DTS 301 — Machine Learning I.

### Week 1 Topics

- What machine learning is
- Conventional programming vs. machine learning
- Machine-learning terminology
- Features, targets and feature vectors
- Classification, regression and unsupervised learning
- Supervised learning
- Training and generalisation
- Training, validation and test sets
- Exploratory data analysis before modelling
- Data leakage
- Responsible machine learning
- Problem formulation before algorithm selection
- ML problem formulation activities
- Iris mini-practical
- Independent practice
- Reflection and bridge to Week 2

### Learning Cycle

**Read → Predict → Run → Observe → Explain → Reflect**

Students should actively work through the examples rather than simply execute the code.

### Important Principle

> **Problem first. Data second. Algorithm later.**

The goal is to understand the machine-learning problem before selecting an algorithm.

### Software

The R pathway is designed for:

- **R**
- **RStudio**
- **R Markdown**

No Google Colab is required for the R pathway.
