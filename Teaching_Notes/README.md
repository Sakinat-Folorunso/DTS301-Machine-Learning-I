## How the Teaching Materials Are Organized

The course uses a three-layer structure:

### 1. Master Teaching Notes

The Google Document contains the lecturer-facing class notes, including:

- learning outcomes
- teaching approach
- explanations
- worked examples
- mathematical formulations
- classroom activities
- guided demonstrations
- formative assessment
- misconceptions
- class tasks
- reflection
- weekly summaries
- bridges to subsequent topics

### 2. Python Student Materials

Python notebooks are provided through Google Colab and GitHub.

### 3. R Student Materials

R materials are provided as R scripts and R Markdown documents designed for RStudio.

---

## Course Learning Philosophy

The course follows the principle:

> **Problem first. Data second. Algorithm later.**

The learning cycle is:

> **Read → Predict → Run → Inspect → Explain → Reflect**

The broader teaching sequence is:

> **Teach → Demonstrate → Interpret → Practise → Do It Yourself → Reflect → Bridge**
