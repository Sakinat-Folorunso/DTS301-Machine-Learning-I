## How to Use the R Materials

1. Download the `.Rmd` file.
2. Open **RStudio**.
3. Select **File → Open File**.
4. Open the `.Rmd` file.
5. Read each section before running the code.
6. Predict the output where prompted.
7. Run each code chunk.
8. Inspect and explain the output.
9. Complete the Class Task and Do It Yourself sections.
10. Use **Knit** to produce the requested output format.
